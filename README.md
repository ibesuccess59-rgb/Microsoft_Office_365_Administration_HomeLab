#  Microsoft 365 Enterprise Administration

##  Project Overview

This project simulates the administration of a Microsoft 365 environment for a fictional organization

The project demonstrates hands-on experience managing users, identities, email, collaboration, SharePoint resources, security, and employee access across Microsoft 365.

The environment was built to practice common tasks performed by Microsoft 365 Administrators, System Administrators, and IT Support teams.
