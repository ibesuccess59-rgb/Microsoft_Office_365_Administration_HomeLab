# Lab 01 - User and License Administration 

## Objective 

This project demonstrates core Microsoft 365 administrative tasks performed in the Microsoft 365 admin center: creating a user account, assigning licenses, updating a user profile, resetting a password, and blocking/unblocking sign-in access. These are foundational, day-to-day tasks for an IT support or systems administrator role.
